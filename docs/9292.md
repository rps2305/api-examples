# 9292 Travel Advice API

## Overview
9292 provides a travel advice API for route planning in the Netherlands. Access requires a commercial agreement and API credentials.

## Python
```python
import requests

base_url = "https://9292.nl/zakelijk/9292-reisadvies-api"
headers = {"Authorization": "Bearer 9292_API_TOKEN"}

resp = requests.get(f"{base_url}/journeys", headers=headers, params={"from": "Amsterdam", "to": "Utrecht"})
resp.raise_for_status()
print(resp.json())
```

## PowerShell
```powershell
$headers = @{ Authorization = "Bearer 9292_API_TOKEN" }
$uri = "https://9292.nl/zakelijk/9292-reisadvies-api/journeys?from=Amsterdam&to=Utrecht"
Invoke-RestMethod -Uri $uri -Headers $headers
```

## curl

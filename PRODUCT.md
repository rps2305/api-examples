# Product

<!-- impeccable:product-schema 1 -->

## Platform

web

## Stack

Static HTML, CSS, and JavaScript with Python event scrapers and a generated JSON feed.

## Users

People in Twente planning a night out while keeping FC Twente fixtures in view. The personal email recipient is Ronald.

## Product Purpose

Bring Metropool, De Cactus, and FC Twente activity into one practical agenda; make concert details and ticket destinations easy to reach.

## Positioning

One local agenda that puts concert options and football fixtures on the same day, rather than making a user compare three separate sources.

## Operating Context

The public static website will be published at `event-calendar.puntuale.nl`. A separate Gmail-delivered HTML digest is sent every Monday at 07:00.

## Capabilities and Constraints

The website is rich, responsive, and static. The email must be inbox-safe HTML and links back to the website. Event content comes only from the local scrapers; no event details are invented.

## Product Principles

- Make a night-out decision quick.
- Keep the live sources and ticket links visible.
- Treat football fixtures as real calendar constraints.
- Make the email a useful summary, not a shrunken website.
